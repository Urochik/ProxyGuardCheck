# ProxyGuardCheck

Инструмент для определения CDN, прокси и Anti-DDoS-защиты по HTTP-заголовкам ответа сервера.

## 📌 О чём это

ProxyGuardCheck отправляет HTTP-запрос к указанному URL, читает заголовки ответа и по характерным сигнатурам определяет, какая CDN или система защиты стоит перед целевым сайтом.

Инструмент полезен на этапе **начальной разведки (recon)**: прежде чем тестировать цель, нужно понимать, чем она защищена и что находится за периметром.

> ⚠️ **Дисклеймер**
> Инструмент предназначен только для легального тестирования собственных систем или систем, на которые у вас есть **разрешение**.
> Автор не несёт ответственности за использование в противоправных целях.

## 🚀 Установка
git clone https://github.com/Urochik/ProxyGuardCheck.git
cd ProxyGuardCheck
pip install requests

🛠 Использование:
python main.py

Скрипт запросит URL:
Proxy/AntiDDOS cheker v0.1
input url to check proxy or cdn: example.com
Можно вводить как с https://, так и без — префикс добавится автоматически.

Пример вывода:
server: cloudflare:
 cf-ray: 8a1b2c3d4e5f
 CF-Cache-Status: HIT
